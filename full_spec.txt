Buildable = cells with slope <= 15% excluding water bodies. Score: >= 0.80 → 100, <= 0.20 → 0, linear between.terrain_roughness (Bhoonidhi CartoDEM): Compute mean Terrain Ruggedness Index (TRI) or local elevation standard deviation (3×3 window) in metres. 3-band lookup: < 3 m → 100, 3–10 m → 60, > 15 m → 20 (linear between). Also report site relief (max - min m) in metadata.land_cover_conversion (Bhuvan LULC): Area-weighted score by LULC class: Barren/Wasteland/Scrub (95), Fallow/Single-crop (65), Irrigated Double-crop (30), Built-up (25), Forest (10), Wetland/Water body (0).geomorphology_constraint (Bhuvan Geomorphology): 3-band lookup: Alluvial plain / Pediplain / Stable upland plateau (100), Dissected plateau / Piedmont / Foothills (60), Active floodplain / Marsh / Steep structural hills (15). Mark missing if unavailable for the region.rainfall_mean_annual (MOSDAC): Piecewise-linear around sustainable township rainfall: < 300 mm → 20, 700–1600 mm → 100, > 2800 mm → 40 (penalizes both arid scarcity and extreme monsoon flood-proneness).rainfall_variability (MOSDAC): Coefficient of Variation (CV) of annual/monsoon rainfall: CV <= 0.15 → 100, CV >= 0.45 → 20, linear between.groundwater_prospect (Bhuvan GWPIS): Good → 100, Moderate → 60, Poor → 20; mark missing and renormalize if unavailable.surface_water_access (Bhuvan Water Bodies): Distance from site boundary to nearest perennial water body (using water_buffer_km: 15): < 2 km → 100, 2–5 km → 75, 5–15 km → 45, > 15 km → 15.flood_hazard (Bhuvan Flood Hazard Zonation / CartoDEM HAND Proxy):Primary (Bhuvan real data): Area-weighted score over site: Very Low=100, Low=75, Moderate=50, High=25, Very High=0.Proxy (when Bhuvan lacks state coverage): Compute HAND (Height Above Nearest Drainage) from CartoDEM using pysheds (pre-computed per demo region in build_region_cache.py and masked dynamically per polygon). demand_MLD(t)        = population(t) * lpcd / 1_000_000
effective_catchment  = site_area_m2 * catchment_area_multiplier
rain_mm(t)           = rain_mean_mm * (1 + rainfall_change_pct / 100)
local_supply_MLD(t)  = (rain_mm(t) / 1000 * effective_catchment * yield_fraction) / 365 / 1000
supply_MLD(t)        = local_supply_MLD(t) + external_supply_MLD + rwh_bonus_MLD
stress_index(t)      = demand_MLD(t) / max(supply_MLD(t), 1e-6)
(1 MLD = 1,000 m³/day. Unit-test sanity checks: 500,000 × 135 lpcd = 67.5 MLD; 150,000 × 135 lpcd = 20.25 MLD.)Calibrated Editable Defaults (config/assumptions.yaml, all marked illustrative default):pop0: 150_000 (Phase-1 greenfield township population in 2026; scales to ~380k–500k by 2050).lpcd: 135 L/person/day (CPHEEO urban standard; confirm citation).catchment_area_multiplier: 3.0 (surrounding watershed runoff contributing to local recharge/reservoirs).external_supply_MLD: 15.0 (baseline canal/river allocation; user can set to 0).yield_fraction by groundwater class: Good = 0.20, Moderate = 0.12, Poor = 0.06 (if missing, use 0.12 and lower confidence).search_buffer_km: 15.0 (for OSM infrastructure), landslide_buffer_km: 5.0, water_buffer_km: 15.0.Scenario Presets:baseline: growth_rate = 0.025, rainfall_change_pct = 0 → stays in safe/moderate range (< 0.8).high_growth_dry: growth_rate = 0.040, rainfall_change_pct = -15 → visibly crosses stress_index = 1.0 around 2038–2044 on stressed sites.conservation: growth_rate = 0.025, lpcd_reduction_pct = 20, rwh_capture_share = 0.10 → pulls stress back below 0.8.Stress Bands: < 0.4 Low | 0.4–0.8 Moderate | 0.8–1.0 High | > 1.0 Deficit.Uncertainty Band: low/base/high runs varying rainfall by -20 / 0 / +10% and growth by -1 / 0 / +1 pp; label chart "Illustrative range, not a forecast".Flood Stress: qualitative shift band (e.g., Stable / Elevated / High Amplification) under positive rainfall change — no fabricated precision.Horizons: expose 2035 and 2050 summaries plus yearly 2026–2050 chart.
